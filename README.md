# Landing Page Specification — AI Creative Production

## Obiettivo

Creare una landing page B2B ad alta conversione per il servizio **AI Creative Production**.

La pagina deve comunicare che l'AI non sostituisce la direzione creativa, ma la rende più veloce, controllabile e scalabile attraverso un sistema integrato di produzione.

Target:

* Aziende
* Marketing Manager
* Brand Manager
* Responsabili Comunicazione
* PMI e aziende strutturate

Tone of voice:

* Professionale
* Strategico
* Premium
* Chiaro
* Orientato al business
